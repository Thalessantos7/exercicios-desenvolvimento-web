# Exercícios de Desenvolvimento Web

Este repositório contém os exercícios práticos desenvolvidos durante a disciplina de Desenvolvimento Web. O progresso está dividido em etapas ("estágios"), começando pelos fundamentos da web e avançando para a criação de interfaces modernas com frameworks JavaScript.

## 🚀 Tecnologias Utilizadas

**Primeiro Estágio:**
* HTML5
* CSS3
* JavaScript

**Segundo Estágio:**
* React
* Next.js
* TypeScript
* Tailwind CSS
